# Assignment 6 · Reference visualization

Explore the completed bar chart, airport map and city bubble chart. Select an
airline by clicking its bar; click it again or use Reset selection to clear.
The three views update together.

The E1–E3 text blocks are intentional placeholders. In Part 6, students write
their own finding headlines and evidence-based commentaries in these locations.
This reference demo shows chart behavior and text placement; use the separate
student starter to complete the assignment.

This is a static website. Keep `index.html`, `styles.css`, `js/`, `data/`,
`lib/` and `SOURCES.md` together, preserving their relative paths. D3,
Bootstrap CSS and both datasets are included locally. No build or package
installation is needed to serve this folder.

For a local preview, open the complete folder in VS Code and use **Open with
Live Server** on `index.html`. See `SOURCES.md` and the third-party library license files for
data provenance and library attribution.
